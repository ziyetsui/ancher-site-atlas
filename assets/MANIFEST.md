# Assets — placeholder image library

AI-generated placeholder images (no real identities). All compressed to **webp**
and renamed to `<category>-<desc>.webp` slugs for fast lookup. Machine-readable
version: [`_manifest.json`](./_manifest.json).

Use these as photo slots in direction sample pages (hero portrait, work tiles,
photo wall, etc.). Prefer the more **artistic / editorial / illustration** ones
for diversity. The 5 directions that already shipped with `thispersondoesnotexist`
faces are intentionally left unchanged.

## How to use
- Reference from a direction page: copy the chosen webp into the direction folder
  (or reference `../../assets/<slug>.webp` if same-origin served), give it
  `class="u-photo"` + an `alt`, and keep the photo-toggle contract.
- Add new images: drop a file in `assets/`, run the convert step, then add a row here.
