23 种文字动效 · 23 Text Animations

纯 HTML / CSS / JS，零依赖、零框架，可直接复制进任何生成页面。重点不是「炫」， 而是让信息更容易被看到、被理解、被记住 —— 适合 hero 开场、金句强调、AI 生成过程、转场页。

01–10 是基础文字动效；11–23 直接萃取自图鉴里 27 个设计方向页面本身已用到的动效 —— 每张卡片下方标注来源方向，可点击查看原页。

每张卡片都有 复制 Prompt 按钮：点一下即可拿到该效果的自然语言提示词，直接丢给任意 AI 前端就能复现这个效果，不必看代码。 卡片进入视野后自动循环播放（一次性动效播完会停顿约 1 秒再重播；连续动效持续运行），也可点击「重播」手动重看；右上角 复制整页源码 拿到全部 23 个效果的单文件实现， 源码中每个效果都有 /* 01 · TYPEWRITER */ 注释分段，方便单独摘取。尊重 prefers-reduced-motion。
